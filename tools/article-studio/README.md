# 文章排版工作台

本机使用的 Markdown 排版工具，连接当前 Jekyll 博客仓库。无需安装 npm 依赖或登录其他服务。

## 打开

在 macOS 访达双击博客目录里的 `打开文章排版工具.command`。首次启动时保持终端窗口打开；浏览器会打开 `http://127.0.0.1:4174`。如果工具已经运行，再次双击只会打开现有页面。也可以在本目录运行 `npm start`。

## 使用

1. 在左侧原稿区粘贴文章，或点“导入 .md”选择文件。导入时会读取常见 YAML 标题、日期，以及首个一级标题。Obsidian 的 `![[图片.png]]` 会转成图片引用，普通 `[[笔记]]` 会显示为文字。
2. 导入后会自动从已关联的 Obsidian `Blog/Assets` 文件夹匹配图片，支持 `../Assets/图片名`、普通 Markdown 图片和 Obsidian 图片引用。原稿中的 `![[图片.jpg|482]]` 宽度会保留到预览、公众号富文本和博客文章，窄屏时图片仍不会超出正文。在编辑区底部展开“关联 Obsidian 图片”可查看路径、重新匹配及缺失原因；也可选择图片文件夹或通过“添加本地图片”补充文件。图片会随博客文章保存；公众号复制时，工具会尝试将本地图片嵌入富文本，未关联的图片会阻止复制并显示名称。远程图片链接仍由原网站提供，可能在公众号中失效。
   博客中未指定宽度的配图最多显示为 520px；公众号二维码最多 140px。已指定宽度的图片继续按原稿尺寸显示，手机端会自动缩进正文宽度。
3. 选中文字后点击“加粗、斜体、下划线、删除线”等按钮即可应用格式；小标题、引用和列表作用于选中行。再次点击可取消相同格式，无需手工输入符号。中栏用两列卡片选择排版方案，再用“正文字号”选择 14–22 px；字号会保留到公众号复制和博客文章。可打开“关于我”，填写公众号名称并选择二维码图片；末尾会写成“欢迎关注公众号：名称”。名称和二维码完全由你提供；未提供时不会虚构公众号信息。
4. 点“复制到公众号”，到微信公众号后台粘贴，并检查标题、图片、链接和版式。复制内容会去掉预览卡片的外框和宽内边距，按手机正文宽度排版；右侧“手机”预览可先检查阅读效果。剪贴板同时包含 HTML 和纯文本；浏览器必须允许剪贴板操作。公众号后台可能过滤内嵌图片；如粘贴后缺图，在“公众号配图备用”中按顺序点击“复制图片”，再到正文相应位置粘贴。逐张复制时会转成 PNG，动图只保留第一帧。
5. 公众号发布后，可在“公众号原文信息（仅博客显示）”填写原文链接和发布时间。导入已有博客 Markdown 时，工具会识别旧文章开头的公众号来源段落及新文章末尾的来源注记并移到这里；复制到公众号时不会带上这些信息。点“保存到博客仓库”后，来源信息会保存在文章元数据中；博客正文末尾、“关于我”的分割线上方以小字显示“*原文链接：文章标题链接”，发布时间不会占据正文。工具会创建 `_posts/日期-标题.md`，若文章有图片也保存到 `img/article-studio/`。同名文章不会覆盖。检查本地文章后，可点顶部“更多操作”里的“发布到线上博客”，或在文章清单点该篇的“发布”；确认后工具会提交这篇文章及引用的图片并推送到博客 GitHub 仓库。若有已检查的本地工具更新，也会一起推送。网站更新取决于 GitHub Pages 构建。
6. 修改导入的 Obsidian 文章后，可点顶部“更多操作”里的“另存为 Obsidian MD”。工具按导入文件名查找其在 `Obsidian Vault/Blog` 下的原文件夹，另存位置和新文件名可在“Obsidian 另存位置”中调整。它会保留原稿中的 YAML 元数据，将新加的本地图片复制到 `Blog/Assets`，并把图片引用改为可从新文件打开的相对路径。同名文件自动加序号，原稿不会覆盖。若 Blog 下有多个同名原稿，需自行选择文件夹。
7. 展开“已保存到博客仓库”，点“检查线上状态”即可看到“仅本地”“有待发布修改”“已同步 GitHub”等状态。文章 Markdown 保存在博客仓库的 `_posts/`，配图保存在 `img/article-studio/`；每篇下方的“查看本地文件路径”会显示完整地址并可复制。点“博客预览”会先在本机构建 Jekyll，再显示这篇已保存文章的完整博客页面，也可在新标签页打开；这不会发布文章或计入线上访问统计。编辑区未保存的内容不会进入博客预览。点“编辑”载入文章，修改后点顶部“更新博客文章”，再点清单中的“更新线上”推送修改。编辑时发布日期固定，修改标题不会更改原文件名和博客链接；点“退出编辑”可保留当前内容并另存为新文章。“打开线上”可检查网站页面，GitHub 推送成功后页面可能稍晚更新。
8. 要让文章从网站消失，点“撤下线上”并确认。工具会提交并推送删除文章的改动；本地 Markdown、配图和 Git 历史仍保留，可再次发布。“删本地”只删除本地 Markdown，不会撤下线上文章；若已发布的文章被本地删除，清单仍会显示“线上仍在，本地已删”，可点“恢复本地”继续编辑，或点“撤下线上”。预览不能完全代替网站页面检查。

## 边界

服务只监听本机 `127.0.0.1:4174`，文章和图片不经过第三方排版服务。发布、更新和撤下线上只允许 `master` 分支、指定的博客远端，且会阻止远端新提交或其他待推送提交。工具不会替你登录公众号或自动发布公众号文章。图片单张上限 5 MB、每篇最多 30 张，整次保存请求上限 16 MB。

排版灵感是经典书籍、现代编辑页和留白阅读等通用方向，不复制其他网站的具体模板。博客使用自己的 Jekyll 排版样式；公众号使用复制时的内联样式，两个平台的显示可能有细微差异。

自动关联只读取指定 Obsidian Blog 目录内被文章引用的图片；另存为 Markdown 时仅在该 Blog 目录中创建新稿和新图片，不修改 Obsidian 原文件。若缺失图片，会显示文件名及原因，保存博客或另存 Markdown 时也会阻止未关联图片。工具源文件已从 Jekyll 网站输出中排除。
