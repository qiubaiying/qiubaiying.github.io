公共层 x-base 三套共用

  • G1 次墨 #666E67 / 暗 #8A928C 专供 ≤13px；大字刻度另用 --x-faint-deco。原 Phase 1 的 #8A928C 用在 11px 仅 3.09:1，已废弃。
  • G2 实线 1px --rule、细分隔 1px --rule-2、占位底 --wash；原 include 的 5 处硬编码灰全部换成 Paper 变量。
  • G3 免责块去灰底：左 2px --mark + 透明底 + 32px 处顶线 + 16px 上内距，13px/1.75 --ink-2。
  • G4 标题 --serif / 编号·level·status·driver --mono + tabular-nums / desc --sans。
  • G5 真封面 alt="" + 16/9 + object-fit:cover，首行 eager/high、其余 lazy；<240px 缩略位用 CSS 色块，不请求 PNG。
  • G6 规划中态不渲染任何 <a>/<button>，状态由真实文本 + aria-label 承担；虚线仅装饰。
  • G7 刻度/踏面线/进度轨的伪元素一律 content:"" 只做几何，几何容器 aria-hidden="true" 或 role="img"。
  • G8 显式覆盖 .sheet a 下划线、.sheet img 外边距、.sheet th/td 的 !important 内边距与末行粗线。
  • G9 卡片只留一个 <a>，aria-labelledby → 标题、aria-describedby → driver。
  • G10 3D 页无返回链接：target="_blank" rel="noopener" + 卡内可见 mono「在新页打开」。
  • G11 术语改 <section id="glossary"> + <dl>/<dt>/<dd>，补页内锚点导航 + 回顶；scroll-margin-top:88px（≤900 → 76px）。
  • G12 prefers-reduced-motion: reduce 下 scroll-behavior:auto。

阅读说明

控制台与预览区共用 Paper 纸墨变量。切换只重写 iframe 的 srcdoc，不重载外层页面、不丢控件状态与滚动位置。预览内「在新页打开」等链接指向本地真实页面，会在新标签打开。

图片路径均为 ../xiuxing/ 下的 7 个 cover PNG 文件名；7 张原图各约 290KB，合计约 2.0MB，故缩略位全部走 CSS 色块。
