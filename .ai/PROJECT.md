# Scond Blog

定位：Tim 的个人博客及本地文章排版工作流。用户是 Tim，目的是用一份 Markdown 文章高质量地发布到博客或粘贴到公众号。

当前版本：Jekyll 博客 + 本地文章排版工作台。首轮验收：粘贴/导入 Obsidian Markdown、六种版式预览、可选个人介绍及公众号信息、公众号富文本复制、本地保存、手动点击后发布到博客。

技术：现有 Jekyll；排版工作台使用 Node 内置 HTTP 服务与浏览器原生 JavaScript，内置 MIT 许可的 marked 解析器，无在线服务依赖。

隐私与部署：原稿和导入图片留在本机，除用户主动点击博客发布外不上传。公众号复制仅进本机剪贴板。博客 `master` 推送可能触发 GitHub Pages 生产发布。工具不保存账号或密钥。

本轮不做：公众号自动登录/发布、AI 改写文章、跨设备同步、批量改造旧文章。
