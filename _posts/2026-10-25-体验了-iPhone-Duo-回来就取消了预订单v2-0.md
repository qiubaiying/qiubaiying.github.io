先说优点：

iPhone Duo 的这款屏幕太喜欢了，磨砂感，看起来赏心悦目，尤其是阅读电子书的时候，像是纸质版

![722B306A-2EC0-4002-BBC3-2E268B515A7C_1_105_c.jpeg](/img/article-studio/2026-10-25-体验了-iPhone-Duo-回来就取消了预订单v2-0/04-df79c403fb9ebc654aecd1d4216537a0424cc298792c39e94705bc9680558160-4fac7511.jpg){: width="520" }

然后，折叠/打开的动画过渡就不说了，世界第1，状态栏的wifi信号多合一，也是很好

屏幕展开后，可用面积非常大，相当于 iPad mini 7 了，可读信息量很大，和 OPPO Find N6 对比了一下，展开后的大小相差无几

![Pasted image 20261025214827.png](/img/article-studio/2026-10-25-体验了-iPhone-Duo-回来就取消了预订单v2-0/05-ab9fe986c9a7f5ce6e354478dec51d113366c770c1be67d43c7dec035c33367e-beaa855b.png){: width="420" }

上面是 iPhone Duo，下面是我的 OPPO Find N6

但是在非展开状态，就有点鸡肋了，那么小的一块屏，用也不是，不用也不是

我觉得展开可能是 iPhone Duo 最佳状态吧

![7404E0DB-63ED-40AA-9A69-FECA9A7BCEEF_1_105_c.jpeg](/img/article-studio/2026-10-25-体验了-iPhone-Duo-回来就取消了预订单v2-0/06-0869ea91b86c13c614bc9466a916c34d9cf80f8a88399fa85f7df4edd19fccc4-807d3941.jpg){: width="420" }

折痕的话，23 号开售，昨天24号去体验时，看到的那台演示机折痕就已经比较明显了

作为对比，我的 OPPO Find N6 用了快 5 个月，折痕还是可以接受的状态，平时使用，亮屏的状态下毫无感知

为什么最后取消了预订单呢
1. 太贵，首发价格 15999 起步，说实话，果粉都有点冲不动了（主因😭）
2. 第一代折叠机，不知道品控怎么样，看到网上有反馈同一个位置屏裂的，感觉要等等再看
3. 拍照/视频效果一般，没办法，所有折叠机的通病，没一个好用的
4. 软件适配还需要时间，等几个月后都适配好了，说不定价格就跌下来了
![Pasted image 20261025220734.png](/img/article-studio/2026-10-25-体验了-iPhone-Duo-回来就取消了预订单v2-0/07-Pasted-image-20261025220734-595bcb94.png){: width="318" }


双持OPPO Find N6的过程中，我觉得折叠机最大的使用场景，就是展开的状态，相比 iPad 平板更便携，分屏的功能十分好用，比如查攻略，一心三用
![Pasted image 20261025222345.png](/img/article-studio/2026-10-25-体验了-iPhone-Duo-回来就取消了预订单v2-0/08-b60050cd51e348ec27594f2a3b1b596408852579e36f0dbdf56d3f41fb623be2-190cba56.png)

偶尔用来微信读书，体验都很好。特别是看英文书，同时打开微信读书 + 词典 + ChatGPT，交互满分

![463EC825-8E03-4804-A45C-EF60D6152F7D_1_201_a.jpeg](/img/article-studio/2026-10-25-体验了-iPhone-Duo-回来就取消了预订单v2-0/09-5b2355098d70f55544b6d2ed61a46b409ed28f2b64945f6b7939c495eea923df-848f8d5f.jpg){: width="420" }

![1FDC90DF-6889-4849-BF75-4727CBF660BD_1_201_a.jpeg](/img/article-studio/2026-10-25-体验了-iPhone-Duo-回来就取消了预订单v2-0/10-1da219065b682d539d677dafe5722b7c98ba22e79c3ad65a2fbf002dba5edf2b-6bb53eaa.jpg){: width="420" }

缺点就是真的重，戴上保护壳，拿在手里不方便，吃饭或者休息，握着也累，于是配了个支架，使用体验提升+10分

但是呢，放在口袋里，裤子都要不停地往下掉。。。如果有一天折叠屏能把重量降下来，那就太好了……
